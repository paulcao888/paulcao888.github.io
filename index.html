FluentPal

Make room for more conversation.

A voice practice prototype with live AI conversations, transcripts, and session reviews for vocabulary and grammar. Built in the AI Polyglot Learning repository.

  • React
  • TypeScript
  • Gemini
Visit prototype ↗Source code ↗
Inside the project +

The implementation connects live audio to Gemini and includes voice and accent-style selectors, transcripts, and AI-generated session reviews. These are practice features; the project does not establish validated pronunciation scores or learning outcomes.

02LANGUAGE LEARNINGWeb app

WordUp

A daily reader of English words.

An editorial-style vocabulary app with spaced repetition, four study modes, and browser-based pronunciation. A quieter way to build a daily learning habit.

  • HTML / CSS / JS
  • SM-2
  • Web Speech
Open WordUp ↗Source code ↗
Inside the project +

A buildless web app with recognition, translation, spelling, and cloze exercises. Progress is saved in the browser on one device. AI-generated mnemonics and cross-device sync are roadmap ideas, rather than shipped features.
